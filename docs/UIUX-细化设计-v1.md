# UI/UX 细化设计 v1

> 承接：`DESIGN.md`（视觉契约）· `docs/产品设计-v3.1-研究校准.md`（儿童可用性证据）· `docs/新用户引导设计-v1.md`
> 定位：把"应该长什么样"落到**每一个像素、每一个手势、每一帧**；并修正早期设计里的两处欠考虑。

## 决策已锁定

| 项 | 结论 |
| --- | --- |
| 任务呈现 | 默认**行式卡 88px**（清单式）；家长端可开"一次只做一件事"聚焦模式（260px 大卡） |

## 一、先修正两处

### 修正 1：任务卡内嵌 72px 全宽按钮 → 一屏只看得到 1.7 张

原来的标准卡高度：`图标行40 + 12 + 点阵20 + 12 + 按钮72 + 内边距32 = 188px`
首页可用高度（375×667）：`667 − 44(安全区) − 140(宝箱区) − 80(布布说) − 72(导航) = 331px`
→ 只能放 1.7 张卡，孩子要看"今天有哪些事"必须滚动。

**改为行式任务卡 88px，整行可点**

```
┌──────────────────────────────────────────┐  88px
│ [图标40]  叫叫阅读          ●●○○○   ⭐3  │  ← 整行 375×88 是命中区
│                            [+1]           │  ← 右侧 56px 胶囊，视觉锚点
└──────────────────────────────────────────┘
```
4 张 = `4×88 + 3×12 = 388px`，滚一屏看全；命中区从 72×340 放大到 88×375。

### 修正 2：宝箱 8 格是硬编码

**按任务数分档**

| 任务数 | 呈现 |
| --- | --- |
| 1–6 | 独立格子 32×32，间距 6（能用手指数） |
| 7–10 | 分段条 8 段，每段 24×20，间距 4 |
| >10 | 单一粗条高 16 + "还差 N 个"（**不出现百分比**） |

规则：图形永远存在，数字只出现在"还差 N 个"里。

## 二、屏幕解剖与手势预算

```
┌─────────────────────────┐ 375px
│ 安全区 44px              │
├─────────────────────────┤
│ ① 头图 140px            │ 渐变 + 孩子名 + 宝箱
├─────────────────────────┤
│ ② 布布说 80px           │ 可点 → 说说话
├─────────────────────────┤
│ ③ 任务区（主命中区 ★）    │ 拇指自然覆盖
├─────────────────────────┤
│ ④ 小世界 96px           │
├─────────────────────────┤
│ ⑤ 导航 72px + 安全区     │ 上留 12px 保护带
└─────────────────────────┘
```

**手势只允许 3 种**

| 手势 | 允许用途 |
| --- | --- |
| 单击 | 一切主操作 |
| 上下滚动 | 浏览 |
| 左右滑 | **仅**说说话快捷气泡 |

**禁止**：长按、双击、拖拽、下拉刷新、侧滑返回（6–8 岁精细动作不足）。

**返回行为**：孩子端**没有返回按钮**，页面深度 ≤1 层；详情用底部弹层，关闭用 56px ✕ 或点遮罩。

```
  │  140×140    │ │  140×140  │   卡片 168×216 圆角 24

```

```
│ 小月亮 的星期天 ☀️                │

│  │ [🎁][🎁][🎁][ ][ ][ ] 还差3个 │ │ 格 32/间距 6
│  │ ▓▓▓▓▓░░░░░                  │ │ 条 8px 双保险
│  └────────────────────────────┘ │
├ ② ⭐ 今天你读了20分钟，还差2个 → ─┤ 80px 整条可点
├ ③ 今天要做 ─────────────────────┤
│ [📖] 叫叫阅读  ●●○○○  ⭐3  [+1] │ 88px
│ [🎒] 学校作业  ●○○○○○○  ⭐2      │ >5 次改分段
├ ④ [🎁商店][🗺闯关5关][🥚签到2/4]  │ 96px 三卡
└ ⑤ 导航 ─────────────────────────┘
```
层级：**宝箱 → 任务行 → 布布说 → 小世界**。

**任务行状态矩阵**

| 状态 | 视觉 |
| --- | --- |
| 默认 | 白底 + 2px `#FFD7EC`；`+1` 渐变胶囊 |
| 按下 | 整行 `scale .98` + 底 `#FFF5FA` |
| 差 1 次 | 描边 `#FF85C1` + 角标「差 1 次」 |
| 已达标 | 底 `#F0FDF4` + 描边 `#22C55E` + ✓ 印章 + 点阵全填 + `+1`→「已完成」 |
| 已停用 | 灰度 40% + 「休息中」 |
| 加载 | 骨架 88px（不转圈） |

### 3.3 打卡反馈时序

| 时间 | 动作 |
| --- | --- |
| 0ms | 整行 scale .98，胶囊 .92 |
| 80ms | 胶囊变印章盖上点阵（1.6→1 回弹） |
| 180ms | 星星飞出（贝塞尔 700ms） |
| 300ms | 点阵第 N 个填充（0→1.2→1） |
| 520ms | 落入宝箱 +1 段，段上微光扫过 |
| 700ms | 达标：翻绿 400ms + 「+3⭐」上浮淡出 |
| 900ms | 达标语音（≤5 次/天，音量 60%） |

约束：**≤1.1s**，期间可继续点下一张；`reduce-motion` 只留底色变化；**300ms 内重复点同一卡合并**。

### 3.4 商店 + 心愿

```
┌ 我的愿望 ────────────────────┐
│ [🎡] 去一次游乐场             │ 112px
```

## 五、视觉节奏

**五层**：L1 头图 140 → L2 宝箱 → L3 任务行 88 → L4 辅助条 80–96 → L5 导航 72

**间距只用 4 个值**：卡间 12 / 卡内 16 / 区块 24 / 头图下 48（4px 仅图标与文字）

**图标**：26（导航）/40（任务行）/20（内联），lucide SVG，`stroke-width:2`，`currentColor`，不混用风格

**插图只用 3 处**：选人页头像、空态、庆典——避免"幼儿园感"，9 岁会抵触

**渐变只用在头图与主按钮**，长页面大面积渐变会显脏；内容区一律浅底。

## 六、声音与触感预算

| 场景 | 声音 | 触感 |
| --- | --- | --- |
| 打卡 | 轻"哒" 80ms/40% | 轻震 10ms |
| 达标 | 上行两音 300ms | 双震 |
| 周达标 | 短旋律 1.2s | 三连震 |
| 兑换 | 清脆"叮" | 单震 |
| 错误/不足 | **不出声** | 无 |
| 导航切换 | **无声** | 无 |

防疲劳四条：同一音效单次会话 ≤6 次 · 语音表扬每天 ≤5 次 · 首次默认开音效关语音 · 静音开关在「我的」56px。

## 八、无障碍

- 对比度全站 ≥4.5:1（`#2E1065` on 渐变 = 12.78）
- 触控：孩子端 ≥56、主操作 72；家长端 ≥44
- **颜色不作唯一信号**：达标 = 翻绿 + 印章 + 「已完成」（三通道）
- 动效全降级；庆典可跳过；无自动轮播
- 系统字号放大 115% 不破版（行高 ≥1.6，卡片自适应）
- `aria-label="叫叫阅读，已完成 2 次共 5 次，达标可得 3 颗星"`
- 主操作集中在屏幕下 60%

## 九、家长端效率 UX

| 场景 | 设计 |
| --- | --- |
| 改奖励 | 行内步进器 40px，**改完自动保存** |
| 批量停用 | 左滑「停用」/ 长按多选（家长端允许长按） |
| 加任务 | 底部 sheet，键盘弹起时按钮跟随 |
| 心愿定价 | 建议区间 50–120⭐ + 三个快捷值 |
| 加载 | 骨架 3 行 |
| 错误 | 行内红字 + 重试 |

**一致性规则**：家长端不做庆祝、不做飞星、不用 72px 按钮。

## 十、交互规格

点击 150ms scale .97（家长 .99）· 页面切换 220ms（家长 0）· 弹层 300ms `cubic-bezier(.32,.72,0,1)` · 关闭 ✕ 56px · 无下拉刷新 · 禁止双击缩放 · 断网打卡进本地队列（顶部细条"没接上，正在重试"）· PIN 输一半切后台清空

---

## 十一、30 项交付走查

**尺寸** ≥56 / 主操作 72 / 卡内无并列按钮 / 间距 ≥16 / 主操作在下 60% / 导航上留 12px
**可读性** 无白字压 `#FF85C1` / 次文字 `#7C4FB0` / 正文 ≥16 / tabular-nums / 金色只做图标
**进度** 无 `3/8` 分数 / 可手指数 / 断签无"失去"文案
**反馈** 每个可点有反馈 / 打卡 ≤1.1s 不阻塞 / 庆典可跳过 / reduce-motion 已降级 / 无自动播放
**合规** 无外链无购买无删除无"设置" / 门两层 / 导出仅门后 / 空态无"暂无数据" / AI ≤40 字 / 危机词
**家长端** 无庆祝 / 行内自动保存 / 骨架 / 行内错误
**一致性** 无硬编码色值 / 二孩各有主色
