## 一、重设计的三个核心判断

**判断 1：孩子端不是 dashboard，是一本会动的童话书。**
现在首页是四个数字卡 + 任务列表，本质是项目管理界面。6-10 岁的孩子不关心"累计 112 颗星"，只关心"我现在要不要按这个按钮、按完会发生什么"。所以孩子端的第一屏必须是**一个大动作 + 一个会发生的惊喜**，数字退到第二层（可点开的"我的星星账本"）。

**判断 2：家长端不是孩子端的放大版，是另一个产品。**
孩子端要"少、慢、有仪式感"；家长端要"密、快、能批量"。同一个品牌、两种密度。家长端是自己的控制台：一眼看到两个孩子今天怎么了、三十秒改完本周任务、一分钟看完周报。

**判断 3：家长定义一切 ≠ 让家长先填一张表。**
出厂必须有**完整可用的模板**（任务、奖励、商店、心愿建议），家长改与不改都能用。设计目标不是"配置能力齐全"，而是"家长第一次打开 3 分钟内能走完，之后每次改动不超过 30 秒"。

由此得出的产品骨架：

```
一个家庭账号
 ├── 孩子 A（独立世界：星星/任务/商店/心愿/宠物/闯关/AI 布布）
 ├── 孩子 B（同上，完全隔离）
 └── 家长（唯一能配置、能看周报、能导出、能兑现心愿的人）
```

## 二、用户在过怎样的两天

### 2.1 孩子的一天（孩子端）

```
场景        放学回家            写作业          睡前
动作        打开 App          点任务卡打卡      逛商店/许愿
触点        选人页→本周         本周             商店→我的
情绪        期待（今天有星星吗） 兴奋（盖章！）      满足 / 期待
关键判断    我的进度在哪         这一下会给我几颗  离愿望还差多少
设计抓手    顶部"离宝箱还差2个"  任务卡上写死奖励    心愿进度条 + 差额
```

**设计结论**：孩子端每个页面的第一行都必须回答"我还要做多少、能得到什么"。

### 2.2 家长的一周（家长端）

```
场景        周日晚上             工作日晚上        周末
动作        设下周任务/奖励        看今天有没有记录   看周报、兑现心愿
触点        家长端·任务          家长端·概览       家长端·周报
情绪        略烦（要配置）        轻松（扫一眼）     有成就感
关键判断    值不值得改             孩子今天做了吗     这周到底进步没
设计抓手    复制上周 + 只改数字    孩子卡片的今日摘要  一张可保存的图
```

**设计结论**：家长端首页 = **孩子卡片列表（每个孩子一张今日摘要卡）**，不是设置列表。设置沉到二级。

## 三、信息架构与导航

### 3.1 端结构

| 端 | 进入方式 | 视觉密度 | 一句话 |
| --- | --- | --- | --- |
| 选人页 `/choose` | 首个孩子之外还有其他孩子时出现，设备记忆上次选择 | 大卡片 | "你要找谁呀？" |
| 孩子端 `/`…`/me` | 无锁 | 大字号、大按钮、一屏一件事 | 玩、看、点 |
| 家长端 `/parent/*` | 从"我的"页齿轮 → PIN | 密、表格、批量 | 配、看、管 |

### 3.2 底部导航（孩子端，7 格）

| 位置 | 现状 | 重设计 | 理由 |
| --- | --- | --- | --- |
| 1 | 本周 | **本周** | 保留，主入口 |
| 2 | 阅读 | **阅读** | 保留 |
| 3 | 动起来 | **动起来** | 保留 |
| 4 | 说说话 | **说说话** | 保留 |
| 5 | 错题本 | **闯关** | 术语儿童化 |
| 6 | 星星 | **商店** | 星星是货币不是页面；商店+心愿是目的地 |
| 7 | 家长 | **我的** | 孩子用语；家长入口藏在这里 |

`我的` 页承载：头像/昵称/宠物/星星账本/换一个人/齿轮（家长锁）。

### 3.3 家长端 IA

```
家长端（PIN 进入）
├── 概览        每个孩子一张今日卡（今日星星、完成数、心情、一句 AI 摘要）
├── 周报        按孩子切换；本周/上周；图片导出
├── 孩子管理    添加/编辑/排序/归档；复制配置
├── 任务        本周任务清单（增删改、AI 生成图标、奖励数、复制上周）
├── 奖励        彩蛋/心情/默认星星规则；周目标
├── 商店        物品（名称/图标/价格/上下架/排序）+ 心愿审批与定价
├── 记录        小日记（按日期/孩子）、对话摘要（可看全文开关）
└── 设置        PIN、家长称谓、提醒、内容与隐私边界、退出家长模式
```

## 四、孩子端设计

### 4.1 选人页

```
┌──────────────────────────────┐
│                              │
│        你要找谁呀？            │
│                              │
│  ┌────────────┐ ┌────────────┐│
│  │   (头像)    │ │   (头像)   ││
│  │   小月亮    │ │   小米粒   ││
│  │  ⭐ 121     │ │  ⭐ 43     ││
│  │ 本周 3/8    │ │ 本周 1/6   ││
│  └────────────┘ └────────────┘│
│                              │
│    （设备记住上次选择，下次直达）  │
└──────────────────────────────┘
```
- 只有 1 个孩子时**不出现**此页。
- 卡片显示本周进度而非累计星星（累计对两个孩子都是比较素材，收起来）。
- 时长按孩子卡片 1 秒可"记住我"，下次跳过。

### 4.2 本周（首页）

```
┌──────────────────────────────┐
│  小月亮  的星期天 ☀️           │
│  ┌──────────────────────────┐│
│  │ 本周宝箱  3 / 8           ││ ← 主进度，孩子在意的唯一进度
│  │ ▓▓▓▓▓░░░░░░░  还差 5 个   ││
│  └──────────────────────────┘│
│                              │
│  ⭐ 布布说：今天你读了20分钟，    │ ← AI 今日入口（P0-2）
│     还差 2 个任务就能开宝箱啦 → │
│                              │
│  今天要做                    │
│  ┌──────────────────────────┐│
│  │ (图标) 叫叫阅读           ││
│  │  2 / 5 次  完成得 ⭐3    ││ ← 奖励前置，孩子看得懂
│  │  ┌────────────────────┐  ││
│  │  │      +1 次         │  ││ ← 整卡大按钮
│  │  └────────────────────┘  ││
│  └──────────────────────────┘│
│  ┌──────────────────────────┐│
│  │ (图标) 学校作业  1/7  ⭐2 ││
│  └──────────────────────────┘│
│                              │
│  我的小世界（横排小卡，可点）      │
│  ⭐ 121 可用  🐶 小黄油  💗 三连  │
└──────────────────────────────┘
```
设计要点：
- **8→任务数由家长定**，宝箱分母自动跟随（家长设几项就几项）。
- 每张任务卡常态展示"完成得 ⭐N"，这是 v1 最大的信息缺失。
- 主按钮只有一个动作 `+1 次`；达标后整卡翻绿并显示 `已完成 ✓`。
- 数字卡降级为页尾横排"我的小世界"，点击进星星账本（孩子版流水：图标 + 星星数，无金额无术语）。

### 4.3 任务完成的两级反馈

| 层级 | 触发 | 反馈 |
| --- | --- | --- |
| 单次 | 点 `+1 次` 未达标 | 卡片盖章动画 + 星星飞入宝箱进度条 + 轻音效 |
| 达标 | 该任务次数满 | 卡片翻绿 + 金色 `+N ⭐` 气泡 + 语音"哇，{昵称}好棒！" |
| 周达标 | 宝箱进度满 | 全屏撒星庆典 3 秒（可点跳过）+ 宝箱开启 + 本周奖励盘点 |

语音台词由系统内置台词池随机（家长可关静音），不接 TTS，避免语调不稳。

### 4.4 阅读

```
今日目标  ▓▓▓▓▓▓░░░  15/20 分钟
本周累计  ▓▓▓▓▓░░░░░  72/100 分钟
连续 3 天 🔥（达标点亮）
宠物 小黄油：肚子有点饿了 →（P1：花星星买食物）
```
- 阅读积分 = 1 分钟 1 分，只涨不跌（保留）。
- 宠物只用星星互动，不做惩罚性状态（避免焦虑）。

### 4.5 动起来

```
本周 2 次 · 65 分钟
周目标 ▓▓▓▓▓▓░░░ 2/3 次
[✓] 跳绳 20 分钟   [ ] 骑车 30 分钟
最好成绩：跳绳 120 个/分钟
```
达标时火苗点亮并给星（奖励数家长设）。

### 4.6 说说话

- 顶部一条**今日回顾条**（"你昨天说跳绳很开心"），让布布先开口，降低孩子不知道说什么的门槛。
- 快捷语气泡：`我今天表现怎么样`、`陪我复盘一下`、`我想许个愿`、`讲个故事`（前两个对应 P0-2 日报）。
- 每个孩子一个布布：头像、名字、口吻独立；聊天里出现的永远是**本孩子**的数据。
- 家长端可看对话摘要；全文可见由家长开关决定。

### 4.7 闯关（原错题本）

```
共 12 关 · 已通关 7 关
┌─────────────┐ ┌─────────────┐
│ 🗺 数学 关卡 3 │ │ 🗺 语文 关卡 5 │
│ 待闯           │ │ 已通关 ✓      │
└─────────────┘ └─────────────┘
```
- 术语全换：错题→关卡、掌握→通关、待复习→再闯一次。
- 视觉用地图/脚印而非表格，保留统计。
- "再闯一次"永远可用（不锁定已通关，允许快乐复习）。

### 4.8 商店（商品 + 心愿）

```
┌──────────────────────────────┐
│ 我的愿望                     │
│ ┌──────────────────────────┐ │
│ │ 🎡 去一次游乐场            │ │
│ │ ▓▓▓▓▓▓▓░░░  85/100 ⭐     │ │
│ │ 再攒 15 颗就能找妈妈兑现啦   │ │
│ └──────────────────────────┘ │
│  + 我有一个新愿望（孩子可提）    │
│                              │
│ 现在可以换                   │
│ ┌────────┐ ┌────────┐        │
│ │📚 绘本  │ │🚲 骑车  │        │
│ │  5 ⭐  │ │ 10 ⭐  │        │
│ └────────┘ └────────┘        │
└──────────────────────────────┘
```
- 心愿在上、商品在下：心愿是长期目标，商品是即时满足。
- 心愿条同时出现在首页与商店，形成"每次得星 → 进度 +1"的持续期待。
- 孩子提心愿只写愿望名（拍照可选）；**定价只能家长做**，孩子看到"等爸爸妈妈定价"。
- 兑付必须家长确认（孩子端显示"可以找{家长称谓}兑现啦"）。

### 4.9 签到（彩蛋 + 心情）

- 4 个彩蛋（数量与奖励家长可配），点开有裂壳动画。
- 心情：5 个表情 + 一句话；写心情得星（家长设）。
- 心情攒成"小日记"，家长端可导出图片（3:4 竖版）。

### 4.10 我的

```
(头像) 小月亮
本月表现徽章：连续阅读 3 天 🔥

我的星星 · 怎么来的
📚 叫叫阅读 +3   3月12日
🧹 做家务   +2   3月12日
🥚 彩蛋     +1   3月11日
🎡 游乐场   -100 3月10日   ← 心愿兑付

🐶 小黄油  💗 (P1 喂养)
换一个人（长按 1 秒）
⚙️（家长锁）
```

## 五、家长端设计

### 5.1 概览（首页）

```
┌──────────────────────────────┐
│ 今天 · 3月12日                │
│ ┌──────────────────────────┐ │
│ │(头像)小月亮  本周 3/8 ⭐29 │ │
│ │ 今日：2 个任务 · 阅读 20 分 │ │
│ │ 心情 😊「今天数学考了100」   │ │
│ │ 布布摘要：数学作业一次做完…  │ │
│ │        [看周报] [去配置]   │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │(头像)小米粒  本周 1/6 ⭐12 │ │
│ │ …                        │ │
│ └──────────────────────────┘ │
│ 待你处理：小米粒提了 1 个心愿 →│
└──────────────────────────────┘
```
- 首页就是"孩子们今天怎么样"，不摆设置。
- "待你处理"聚合需要家长动作的事：新心愿待定价、待兑现、模板未确认。

### 5.2 任务配置

```
本周任务（小月亮）           [复制上周]
┌──────────────────────────────┐
│ (图标) 学校作业   7 次  ⭐2  ⋮│
│ (图标) 叫叫阅读   5 次  ⭐3  ⋮│
│ (图标) 小帮手     3 次  ⭐2  ⋮│
└──────────────────────────────┘
[ + 添加任务 ]
   ↑ 添加时：名称 →（可选）让豆包画图标 → 次数 → 奖励 ⭐ → 保存
```
- 列表直接行内改数字（步进器），不点进详情页。
- `⋮` 菜单：编辑、排序、本周停用、删除。
- "复制上周/复制另一个孩子"是效率核心。
- 图标生成失败：自动落系统图标，保存不阻塞。

### 5.3 商店与心愿

- 商品：名称、图标、价格、描述、上下架、排序；支持"从模板一键补齐"。
- 心愿队列：`待定价` → `攒星中` → `可兑现` → `已兑现` 四态，一屏看清。
- 定价时给出建议区间（"同类心愿 50-120 ⭐"），避免家长定价过高打击孩子。

### 5.4 周报

```
小月亮 · 本周成长报告          3/6–3/12
达标 3/8     阅读 140 分钟 ↑20%
运动 3 次    星星 +29 / -10
布布看到：
· 数学作业从 3 次拖到 7 次，一次比一次快
· 睡前阅读最稳定，周末容易断
下周建议：
· 把阅读目标从 5 次减到 4 次，先把连续性做稳
[ 保存图片 ]
```
- 数字必须与各页一致（同一孩子、同一周）。
- 空态：本周还没有记录 → 给出"从今天开始的小目标"引导，不编造。

### 5.5 设置

PIN（4-6 位）、家长称谓、提醒开关、内容与隐私边界（AI 话题边界、日记家长可见、导出开关）、退出家长模式。

## 六、二孩机制

| 场景 | 设计决定 | 理由 |
| --- | --- | --- |
| 数据隔离 | 星星、任务、商店、心愿、宠物、闯关、心情、AI 记忆全部互不可见 | 比较会导致激励反噬 |
| 星星池 | 不共享，不互相转账 | 转账会变成家庭社交与争夺 |
| 选人 | 选人页 + 设备记忆；`我的` 页长按"换一个人" | 日常零摩擦，防误触 |
| 配置 | 独立配置；"复制老大的任务/商店"一键复制定义，不复制进度 | 家长效率 vs 进度不被覆盖 |
| 家长对比 | 概览页天然并排（两张卡），不做排行榜；周报可切换看 | 家长需要洞察，孩子不需要排名 |
| 孩子端比较 | **零**：不显示对方进度、不发"姐姐比你多"的提醒、AI 禁止生成比较句式 | 产品底线 |
| AI | 每个孩子独立布布（名字/头像/口吻）；只喂本孩子数据 | 避免"同一个布布同时夸两个人"的记忆串味 |
| 心愿 | 独立心愿单；家长可以同时看到两个孩子的心愿队列 | 兑现要高效 |

## 七、家长定义一切：配置模型

### 7.1 一族三件套（家庭 / 孩子 / 模板）

- **家庭**：登录、家长称谓、PIN、提醒、边界。1 份。
- **孩子**：姓名、头像、称谓、出生年、AI 人设名、宠物、周目标、星星规则。N 份。
- **模板**：任务、奖励、商店、心愿建议的出厂默认值。1 份，全局共享，家长改动只写进"孩子"，不污染模板。

### 7.2 可配置清单

| 类别 | 家长可定义 | 出厂默认 |
| --- | --- | --- |
| 孩子 | 姓名、头像、称谓、出生年、AI 人设名/头像 | 首次引导必填姓名头像 |
| 任务 | 名称、图标（字符/相册/豆包生成）、目标次数、达标奖励⭐、颜色、排序、停用 | 6 项小学模板 |
| 周期 | 本周生效 / 自动继承上周 / 按星期重复 | 自动继承上周 |
| 彩蛋 | 每日个数、每个⭐数、名称图标 | 4 个 × 1⭐ |
| 心情 | 写心情得⭐ | 2⭐ |
| 商店 | 物品名、图标、价格、描述、上下架、排序 | 6 项 |
| 心愿 | 审批、定价（可代提） | 无 |
| 周目标 | 每周达标任务数 | 8 |

| 换算文案 | 1⭐=几分钟动画/几元零花（仅说明） | 1 分钟/1 元 |
| 边界 | AI 话题边界、日记可见性、导出开关 | 家长可见=开 |

### 7.3 三条不变式

1. **永不空白**：未配置 → 模板兜底；孩子端任何一页都不会出现"未设置"。
2. **只读给孩子**：孩子端不出现任何管理入口；配置只走家长端。
3. **只影响未来**：改奖励/价格不影响已发放星星与已成交订单；保存时明示"立即生效 / 下周生效"。

## 十二、可用性与无障碍（儿童版硬约束）

- 触控：主按钮 ≥48×48，卡片整卡可点，相邻可点区域间距 ≥8px。
- 字号：正文 ≥14px，数据 ≥28px，底部导航 10px 已在下限，不再缩小。
- 对比度：深紫 `#4A2666` on 白 ≥7:1；白字 on 渐变需加 12% 黑色遮罩保证 ≥4.5:1。
- 动效可关：系统"减少动态效果"时关闭庆典与飞星。
- 声音可关：静音开关在"我的"，家长端也有全局开关。
- 防误触：消耗星星的操作需一次确认；不可逆操作（删任务）只在家长端。
- 家长锁：PIN 4-6 位，5 次错误静默回孩子端首页，家长端 15 分钟超时。
