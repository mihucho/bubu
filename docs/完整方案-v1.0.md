## 1. 一句话定位与核心判断

**定位**：面向 6–10 岁儿童的家庭学习激励与成长陪伴应用。用「星星」把行为变成可见的正反馈，用 AI 布布陪孩子复盘，用家长端把"配置 + 看见变化"收在一个地方。

### 四个核心判断

**判断 1：孩子端不是 dashboard，是一本会动的童话书。**
现状是"4 个数字卡 + 任务列表"，本质是项目管理界面。孩子不关心"累计 112 颗星"，只关心"按这个按钮会发生什么"。第一屏必须是**一个大动作 + 一个会发生的惊喜**，数字退到第二层。

**判断 2：家长端不是孩子端的放大版，是另一个产品。**
孩子端「少、慢、有仪式感」；家长端「密、快、能批量」。同品牌，两种密度。

**判断 3：家长定义一切 ≠ 让家长先填表。**
出厂必须有完整模板，改与不改都能用。目标不是"配置齐全"，而是"首次 3 分钟走完，之后每次 30 秒"。

**判断 4：AI 的价值不在"会聊天"，在"查得准、记得住、不编造"。**
所以模型不喂数据，改为**主动调用只读工具**；对话有分层记忆；数字永不进摘要。

### 二孩的产品底线

**孩子端永不出现任何横向比较**（无榜、无"姐姐比你多"、AI 禁止生成比较句式）。家长端可通过概览并排了解，但不做排行榜。

## 2. 用户与两条主线

### 孩子的一天

| 场景 | 放学回家 | 写作业 | 睡前 |
| --- | --- | --- | --- |
| 动作 | 打开 App | 点任务卡打卡 | 逛商店/许愿 |
| 情绪 | 期待 | 兴奋（盖章） | 满足/期待 |
| 关键判断 | 我的进度在哪 | 这一下给我几颗星 | 离愿望还差多少 |
| 设计抓手 | 宝箱格子（不是分数） | 任务卡写死奖励 | 心愿进度条 + 差额 |

### 家长的一周

| 场景 | 周日晚上 | 工作日晚上 | 周末 |
| --- | --- | --- | --- |
| 动作 | 设下周任务/奖励 | 扫一眼今天 | 看周报、兑现心愿 |
| 关键判断 | 值不值得改 | 孩子今天做了吗 | 这周到底进步没 |
| 设计抓手 | 复制上周 + 只改数字 | 孩子卡片上的今日摘要 | 一张可保存的图 |

## 3. 信息架构与端结构

```
家庭账号 family_accounts（登录 / 家长称谓 / PIN / 提醒 / 边界）
 ├── 孩子 A  child_profiles（星星·任务·商店·心愿·宠物·闯关·日记·AI 记忆）
 ├── 孩子 B  同上，完全隔离
 └── 家长（唯一能配置、看周报、导出、兑现心愿的人）
```

| 端 | 路由 | 进入方式 | 密度 | 一句话 |
| --- | --- | --- | --- | --- |
| 选人页 | `/choose` | 有 ≥2 个孩子时出现；设备记忆上次选择 | 大卡片 | 你要找谁呀？ |
| 孩子端 | `/` `/reading` `/exercise` `/chat` `/quests` `/stars` `/checkin` `/me` | 无锁 | 大字号大按钮 | 玩、看、点 |
| 家长端 | `/parent/*` | 「我的」页齿轮 → 家长门 | 表格、批量 | 配、看、管 |

**底部导航改 5 格**（依据：Smashing「避免底部按钮，孩子常误触」+ NN/g 误触实测；7 格 10px 标签低于儿童可读下限）：
`本周 · 阅读 · 动起来 · 说说话 · 我的`

商店 / 闯关 / 签到 → 首页「我的小世界」三张大卡片（≥96px）。**8 个页面一个不删，只改入口。**

**家长端 IA**
```
概览（每个孩子一张今日卡 + 待处理）
周报（按孩子/按周，图片导出）
孩子管理（增删改排序、复制配置）
任务（行内改数字、AI 生成图标、复制上周）
奖励（彩蛋/心情奖励、周目标、使用管理）
商店（物品增删改上下架 + 心愿审批定价）
记录（小日记按日期/孩子、对话摘要与审计）
设置（PIN、称谓、提醒、内容边界、退出家长模式）
```

## 4. 孩子端设计

### 4.1 首页（本周）

```
小月亮 的星期天 ☀️
┌ 本周宝箱 ────────────────────┐
│ [🎁][🎁][🎁][ ][ ][ ][ ][ ] 还差 5 个 │   ← 格子数=家长设的任务数
└─────────────────────────────┘
⭐ 布布说：今天你读了 20 分钟，还差 2 个就能开宝箱啦 →
今天要做
┌ (图标) 叫叫阅读 ──────────────┐
│ ●●○○○  完成得 ⭐3             │
│ ┌──────── + 1 次 ────────┐   │  ← 72px，整卡可点
└─────────────────────────────┘
我的小世界： ⭐121  🐶小黄油  🎁商店  🗺闯关  🥚签到
```

### 4.2 五个页面要点

| 页面 | 关键设计 |
| --- | --- |
| 阅读 | 今日 + 本周双进度；连续天数达标点亮火苗（**断签不清零**，只显示"重新开始第 1 天"） |
| 动起来 | 周目标次数 + 火苗；最好成绩只和自己比 |
| 说说话 | **语音输入为主**（72px 麦克风）+ 快捷气泡；AI 回复 ≤40 字 |
| 闯关（原错题本） | 关卡地图；错题→关卡、掌握→通关；"再闯一次"永远可用 |
| 商店 | 上：心愿 + 攒星进度；下：家长配置的兑换物；心愿只能家长定价 |
| 签到 | 彩蛋裂壳动画 + 心情记录；攒成小日记 |

### 4.3 反馈三级

| 层级 | 触发 | 反馈 |
| --- | --- | --- |
| 单次 | 点 +1 未达标 | 盖章动画 + 星星飞入宝箱 + 轻音效 |
| 达标 | 该任务满 | 卡片翻绿 + `+N⭐` 气泡 + 语音"哇，{昵称}好棒！" |
| 周达标 | 宝箱满 | 全屏撒星 3 秒（可跳过）+ 宝箱开 |

### 4.4 儿童端硬约束

- 主操作 **72px**、次操作 **56px**、相邻可点间距 ≥16px、卡内禁止并排两按钮
- 正文 **16px**、导航标签 **12px**（原 10px 不合格）
- 错误恢复用文字大按钮「**点错了？改一下**」（孩子找橡皮擦，不认 undo 箭头）
- 指令统一写「点这里」，不写"用鼠标/点击屏幕"
- 孩子端零外链、零购买、零广告、零分享、零删除、零"设置"字样
- `prefers-reduced-motion` 时庆典降级为静态卡

## 6. 二孩机制

| 场景 | 决定 | 理由 |
| --- | --- | --- |
| 数据隔离 | 星星/任务/商店/心愿/宠物/闯关/日记/AI 记忆全部隔离 | 比较会反噬激励 |
| 星星池 | 不共享、不转账 | 转账会变成家庭争夺 |
| 选人 | 选人页 + 设备记忆；「我的」页长按 1 秒"换一个人" | 日常零摩擦 + 防误触 |
| 配置 | 独立配置 +「复制老大的任务和商店」（只复制定义，不复制进度） | 家长不必录三遍 |
| 家长对比 | 概览天然并排；不做榜；周报可切 | 家长要洞察，孩子不要排名 |
| AI | 每个孩子一个独立布布（名字/头像/口吻/记忆）；只喂本孩子数据 | 避免记忆串味 |
| 越权 | 服务端强制 `childId` 与会话绑定，模型/前端均不可指定 | 物理隔离 |

## 7. 家长定义一切（配置模型）

### 7.1 三类对象

- **家庭**（1 份）：登录、家长称谓、PIN、提醒、内容边界、使用管理
- **孩子**（N 份）：姓名、头像、称谓、出生年、AI 人设名、宠物、周目标、星星规则
- **模板**（1 份）：任务/奖励/商店/心愿建议的出厂默认；家长改动只写入"孩子"，不污染模板

### 7.2 可配置清单

| 类别 | 家长可定义 | 出厂默认 |
| --- | --- | --- |
| 孩子 | 姓名、头像、称谓、出生年、AI 人设名/头像 | 引导必填姓名头像 |
| 任务 | 名称、图标（字符/相册/豆包生成）、目标次数、达标奖励⭐、颜色、排序、停用 | 6 项小学模板 |
| 周期 | 本周 / 自动继承上周 / 按星期重复 | 自动继承上周 |
| 彩蛋 | 每日个数、每个⭐、名称图标 | 4 个 × 1⭐ |
| 心情 | 写心情得⭐ | 2⭐ |
| 商店 | 物品名、图标、价格、描述、上下架、排序 | 模板 6 项 |
| 心愿 | 审批 + 定价（可代提） | 无 |
| 周目标 | 每周达标任务数 | 8 |
| 宠物 | 名字、种类 | 小黄油/小狗 |
| 使用管理 | 每日时长 40min、休息间隔 20min、睡眠 21:00–07:00 | 见 §11 |
| 边界 | AI 话题边界、日记家长可见、导出开关 | 家长可见=开 |

### 7.3 三条不变式

1. **永不空白**：未配置 → 模板兜底；孩子端任何页不出现"未设置"
2. **只读给孩子**：配置只走家长端，孩子端无管理入口
3. **只影响未来**：改奖励/价格不影响已发星星与已成交订单；保存时明示"立即生效 / 下周生效"

### 7.4 分龄模板（6–8 / 9–12）

| 维度 | 6–8 岁 | 9–12 岁 |
| --- | --- | --- |
| 文案 | 全图形 + 短句 + 语音朗读 | 图形 + 完整句子 |
| 打卡 | 一键 ±1 | 可一次记多次 |
| 数据 | 只看今天与宝箱 | 加本周/趋势 |
| 布布 | 更撒娇、短句 | 更像同伴 |
| 默认任务 | 3–4 项 | 6–8 项 |

依据：NN/g 与 Smashing 一致——设计跨度不超过 2 岁。

## 8. 星星经济学与激励模型

| 项 | 规则 |
| --- | --- |
| 获得 | 任务达标、彩蛋、写心情、阅读/运动达标（均家长定价） |
| 消耗 | 商店兑换、心愿兑付、宠物食物（P1） |
| 重置 | 本周星星与宝箱进度周一重置；可用/累计星星永不清零 |
| 流水 | 所有加/减星写 `star_ledger`（来源、去向、余额） |
| 汇率 | **取消"1⭐=1 元/1 分钟动画"**——外驱最强、最易崩 |

### 三条内驱支柱（对抗纯代币经济）

| 支柱 | 机制 |
| --- | --- |
| 自主 | 今天先做哪个由孩子定；宠物装饰自选；心愿自己提 |
| 胜任 | 个人最好记录（最快一次、连续 3 天）；**永不显示他人数据** |
| 关联 | "帮妈妈做一件小事"任务类型；布布记得孩子说过的事 |

依据：Smashing 引 Rodrigo Seoane 的批评 + 自我决定理论。另：**不做会清零的连续天数威胁**（损失厌恶对儿童不宜）。

## 9. AI 布布（工具化 + 多轮 + 记忆压缩）

### 9.1 三段式架构

```
客户端 → ChatSessionService（历史窗口 + L1 摘要 + L2 画像 + 静态 system）
       → AgentLoop（≤3 步：选工具 → 执行 → 再决定 → 出答案）
       → ToolRegistry（只读 · 强制 childId · 结果裁剪 · as_of）
       → Postgres
```

### 9.2 工具清单（11 个，P0 做 8 个）

| 工具 | 用途 |
| --- | --- |
| `get_today_snapshot` | **复合**：今日任务/得星/阅读/运动/心情/彩蛋/距周目标 → 80% 对话只需 1 次调用 |
| `get_child_profile` | 星星、周目标、连续天数、宠物 |
| `get_week_tasks` | 任务进度与奖励 |
| `get_star_ledger` | 星星从哪来花到哪去 |
| `get_reading` / `get_exercise` | 按天查询 + 汇总 + 最好成绩 |
| `get_mood_notes` | 心情与小日记（按家长开关裁剪） |
| `get_wrong_questions` | 闯关统计 |
| `get_shop_items` / `get_wish_progress` / `get_reward_rules` | 商店、心愿、「做完得几颗星」 |

**统一返回**：`{ ok, as_of, data, empty }`；`empty:true` 让"今天还没有记录"可验证。
**参数永不含 `childId`**——服务端从会话注入。

### 9.3 两条实施路径

| 路径 | 条件 | 做法 |
| --- | --- | --- |
| **B（先做）** | 当前插件只吃 prompt | 规划轮只输出 JSON `{action,tool,args}`，执行后进入下一轮，≤3 次强制收尾 |
| A（后切） | 插件支持 tools/tool_choice | 标准 `tool_calls → tool message` 循环 |

工具层与会话层做成与路径无关，切 A 只改 AgentLoop 一处。

### 9.4 记忆分层与自动压缩

| 层 | 内容 | 预算 |
| --- | --- | --- |
| L0 工作记忆 | 最近 12 条原文 | 1200 token |
| L1 会话摘要 | 滚动合并，**体量恒定** ≤200 字 | 300 token |
| L2 长期画像 | 跨 session 稳定事实/禁忌 ≤10 条 | 300 token |
| system | 人设 + 铁律 | 800 token |
| 工具结果 | 本轮临时 | ≤1500 token |

**四条压缩原则**
1. 压缩的是提示词视图，`chat_messages` 只增不删（家长可回看原文）
2. **数字不进长期记忆**——旧数字会过期并诱发编造；需要时查工具
3. 情绪与承诺永不压缩掉（`emotions` / `open_loops`）
4. 异步执行、失败可回退、摘要可重建

**摘要 schema**（固定 JSON，不用自由文本）
```json
{ "v":1,
  "summary":"聊了数学小测，情绪从难过转为被鼓励；答应明天讲恐龙故事。",
  "facts":[{"k":"喜欢","v":"霸王龙","at":"2026-03-11"}],
  "emotions":[{"emotion":"难过","cause":"数学72分并觉得被说粗心","at":"2026-03-11","handled":true}],
  "open_loops":[{"text":"答应明天讲恐龙故事","due":"2026-03-12","done":false}],
  "avoid":["不要转述妈妈的负面评价"],
  "drops":{"numbers":3,"tool_json":1} }
```

**触发**：未摘要消息 >16 条 / token >1800 / 空闲 10 分钟 / 跨天 / session 关闭 / 家长手动。单轮最多一次，间隔 ≥30s。

**危机例外**：命中危机词表 → 打 `safety_flag` 永久保留、当轮强制安抚、家长端「需要关注」、`handled:false` 优先回访。**优先级高于所有 token 预算。**

### 9.5 防编造三道闸

1. **事实源唯一**：数字只能来自工具结果
2. **数字白名单校验**（服务端）：回复中的数字 vs 本轮工具结果数字集合，不匹配 → 一次自检重写 → 仍失败替换安全话术 + 埋点
3. **空态强制话术**：`empty:true` 必须出现"还没有记录"

### 9.6 预算与降级

工具 ≤3 次/轮、总 ≤9s、单工具 ≤800ms、孩子端生成 ≤120 token。
降级链：工具失败 → snapshot 兜一次 → 固定话术 + 埋点。

### 9.7 人设与边界

名字 = 该孩子的 AI 人设名（默认=孩子昵称）；6–10 岁天真爱撒娇；回复 ≤40 字 + 1 个表情。
不编造、不评价家长、不转述家长负面评价、不比较兄弟姐妹、不引导多玩手机、不做购买引导。
删除现有 prompt 里的 5 角色设定（妈妈/爸爸/爷爷/奶奶）与全量数据块；删除"布布→昵称"的全文替换逻辑（会误伤第三人称）。

## 10. 视觉与前端标准

## 11. 合规与安全

| 要求 | 来源 | 做法 |
| --- | --- | --- |
| Kids 类不得有外链/购买/干扰，除非在家长门后 | Apple 1.3 | 孩子端零外链零购买；家长门后才开放 |
| 不得向第三方发送可识别信息、不得含三方分析/广告 | Apple 1.3 | 不接广告与三方 SDK |
| 分龄 + 使用时段/时长/内容/功能默认设置可调 | 未成年人模式建设指南 | 使用管理三件套（见下） |
| 14 岁以下需监护人同意、信息最小化 | PIPL / 未成年人网络保护条例 | 家长身份确认；不采真实姓名；头像自选 |
| 家长可查看、可删除孩子数据 | PIPL 撤回同意 | 「删除该孩子全部数据」（软删） |

**家长门（两层）**：① 认知题（点"七"、3+4）→ ② PIN 4–6 位。5 次错误静默回孩子端首页；15 分钟超时。
依据：BabyBus 用"识别繁体数字"做内容墙（NN/g 实测记录的正例）。

**使用管理（P0）**

| 设置 | 默认 | 行为 |
| --- | --- | --- |
| 每日时长 | 40 分钟 | 到点内容墙"今天到这里啦，明天见"，仅家长门可延长 |
| 休息间隔 | 连续 20 分钟 | 强制休息 5 分钟（呼吸动画，无内容） |
| 睡眠时段 | 21:00–07:00 | 不可用 + 内容墙 |

文案不惩罚：「眼睛要休息啦」。

## 12. 本期 P0 范围与验收

前置：P0-0 / P0-6 / P0-7 / P0-8 先于其余（它们决定数据模型与端结构）。

| 编号 | 核心改动 | 验收要点 |
| --- | --- | --- |
| **P0-0 家庭多孩地基** | 家庭 1:N 孩子；全部业务数据挂 `child_id`；星星流水；服务端硬隔离 | 切换孩子后 8 类数据与 AI 记忆全切换无残留；越权 404 |
| **P0-6 家长配置中心** | 任务/奖励/彩蛋/心情/商店/心愿定价/周目标/孩子档案/分龄模板/使用管理 | 零配置可用；改奖励后新打卡按新值、历史不回滚；删任务后卡片消失但流水保留 |
| **P0-7 家长门** | 认知题 + PIN；孩子端零外链零购买 | 家长首次通过 ≤10s；孩子 5 次失败静默退出 |
| **P0-8 使用管理** | 时长/休息/睡眠 + 内容墙 | 到点无内容可看；延长仅家长门可操作 |
| **P0-1 奖励可见 + 庆典** | 任务卡写死"完成得 ⭐N"；三级反馈 | 最后一项完成触发庆典并按家长设定入账；重复打卡不重复加星；庆典不阻塞 |
| **P0-2 AI 成长日报** | 「布布说今天」入口 + 快捷气泡；工具化对话 | 问表现引用真实数字；无记录时如实说明不编造；回复 ≤40 字 |
| **P0-3 家庭心愿单** | 孩子提愿 → 家长定价 → 攒星进度 → 家长兑现 | 攒满可兑付且余额正确并写流水；不足提示差额；重复点击不重复扣 |
| **P0-4 家长周报** | 按孩子生成：达标/阅读/运动/星星收支/AI 观察/下周建议 + 图片导出 | 数字与各页一致；空态不编造；二孩各一份 |
| **P0-5 闯关记录** | 错题→关卡、掌握→通关，地图化 | 通关数 +1 且移出待闯；历史数据完整保留 |
| **P0-9 内驱三支柱** | 自主选择、个人最好记录、家庭小任务 | 首页可"今天先做这个"；个人记录只与自己比 |

**明确不做**：排行榜、社交、付费商城、广告、打卡圈子、孩子间比较、文本/PDF 导出。

## 14. 指标（按孩子采集，按家庭聚合）

| 指标 | 口径 | 目标 |
| --- | --- | --- |

| AI 工具调用/轮 | 平均 | ≤1.5 |
| AI 幻觉率 | 数字校验失败/总回复 | <1% |
| 摘要数字污染率 | 摘要含数字比例 | 0 |
| 儿童端误触率 | 5 分钟内误触次数 | <1 |

## 15. 风险

| 风险 | 对策 |
| --- | --- |
| 二孩比较压力 | 孩子端零比较；AI 禁生成比较句式；家长端对比默认折叠 |
| 纯代币经济削弱内驱 | 内驱三支柱 + 取消汇率 + 断签不清零 |
| 家长配置门槛 | 模板兜底 + 复制上周/复制另一个孩子 + 行内改数字 |
| AI 编造 | 工具即事实源 + 数字白名单 + 空态话术 |
| 插件不支持原生 tools | 路径 B 兜底，接口层抽象，切换只改一处 |
| 压缩丢安全信息 | 危机信令永久保留（硬红线） |
| 家长门被孩子破解 | 认知题 + PIN 双层；5 次静默退出 |
| 儿童沉迷 | P0 使用管理三件套（合规要求） |
| 图片导出兼容 | 服务端渲染 PNG + 长按保存兜底 |

### 17.3 AI system prompt（骨架）

```
你是{孩子昵称}的布布。6-10 岁，天真爱撒娇，说话短、用词简单。
长度：每条 ≤40 字 + 1 个表情。
铁律：
1) 数字只能来自工具返回，没有就别说；
2) 工具返回 empty=true 时如实说"今天还没有记录"，再鼓励一句；
3) 不评价家长、不转述家长负面评价、不比较兄弟姐妹；
4) 不引导多玩手机，到点提醒休息；
5) 直接说人话，不要 JSON、不要 markdown、不要列表。
今天：{date}（周{weekday}）；本周从 {week_start} 开始；家长称谓：{parent_role}
```

### 17.5 实现判断标准

> 需要"把所有数据查出来再给模型"的代码，就是要删掉的代码。
> 模型答出一个没经过工具的数字，就是缺陷。
> 摘要里出现星星数，是 bug；摘要里丢了孩子的情绪或约定，是事故。
> 孩子端点不中的按钮，就是设计缺陷，不是用户问题。
