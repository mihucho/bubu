## 附录 A：壳结构审计（R10，2026-10-22 新增）

**脚本**：`scripts/audit-shell.mjs`（`npm run audit:shell`）

**规则**：`.screen` 的直接子元素必须按顺序是 ① `.statusbar` ② 页头（可省）③ 唯一滚动区 ④ 导航（可省）；页头不得进入滚动区；滚动区不得多于一个；`.chatwrap` 为唯一允许的复合形态（须含 `.chatbody`）。

**结果**：117 页 **0 项**。

**背景**：本轮修复了孩子端二级页的结构错位——`.dbar` 曾被拼进 `<div class="scroll">` 内部，导致滚动区宽度算成 0、内容溢出手机外（`kid-shop` 为典型）。修法落在生成器：`_lib.py` 的 `shell()` 改为以 `<div class="scroll">` / `.pbody` 为分界做结构化切分（页头在前、正文在后），输出固定顺序，不再事后用正则搬 DOM。

**已知取舍**：`.chatwrap` 保留复合容器（聊天页头部固定 + 气泡区滚动 + 输入条固定的三明治结构），不强行拆成四行。

**同时补的样式**：滚动区 `padding-bottom: 22px`，避免最后一行内容被导航压住半行。
