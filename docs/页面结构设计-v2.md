## 一、四个壳 + 一个宽屏变体

| 壳 | 用途 | 宽度 | 导航 | 密度 |
| --- | --- | --- | --- | --- |
| `GateShell` | 登录 / 注册 / 忘记密码 | 375 | 无 | 家长 44px |


**宽屏**：`ParentShell` 在 ≥760 时左 320 列表 + 右详情；`KidShell` 保持单列（平板只做卡片双列）。

## 三、路由守卫（顺序不能变）

```
1. 未登录                               → /auth/login
2. 已登录 & 无有效 consent              → /setup/consent（其它 /setup/* 重定向回来）
3. 已登录 & setup 未完成                → /setup/{setup_step}（断点续上）
4. 访问 /   & children.length > 1 & 无当前孩子 → /choose
5. 访问 /parent/**  & 家长密码未解锁     → 静默 404（不跳转，避免孩子猜路径）
6. 访问 /parent/**  & 20 分钟无操作      → 自动上锁并回 /me
7. 孩子端 & 使用被拦截（超时/休息/睡眠）  → /wall/{timeout|rest}
```

`parentMode` 只存内存，刷新即失效。

**环境判定只有一个布尔**：`inDoubao`（通过 UA 含 `Doubao` 或平台注入标记判断）。在豆包内走 SSO，不在豆包内走手机号登录；其余交互不做环境分支。

## 六、状态管理

| 状态 | 归属 | 说明 |
| --- | --- | --- |
| 登录态 / family / consent | `SessionContext` + `GET /api/auth/me` | 启动与登录后各拉一次 |
| children[] / currentChildId | `FamilyContext` | currentChildId 存 localStorage |
| 家长密码解锁 | `ParentModeContext`（内存） | 刷新失效；20 分钟超时 |
| 使用墙 | `UsageContext` | 30 秒轮询 `/usage/state` |
| 服务端数据 | **react-query** | Context 只管上面四样 |
| 打卡乐观更新 | `use-checkin` | `onMutate` 预加，`onSettled` 以服务端为准 |
| 离线队列 | `use-offline-queue` | localStorage + 幂等键补交 |

**queryKey 约定**

```
['me']                                  family + children + setup
['overview', childId]                   首页聚合（一次拿全）
['task', childId, taskId]
['ledger', childId, cursor]
['messages', childId, toRole]
['wishes', childId]
['shop', childId]
['quests', childId, status]
['report', childId, range]
['parent', 'children', familyId]
```

失效规则：任何加减星 → invalidate `['overview', childId]` + `['ledger', childId]`；打卡 → `['task', childId, taskId]`。

## 七、API 契约

```json
{ "ok": true,  "data": {}, "error": null }
{ "ok": false, "data": null, "error": { "code": "PHOTO_REQUIRED", "message": "要拍一张才能完成", "retryable": false } }
```

## 十、性能与边界

- 孩子端首屏**只请求 1 个聚合接口** `/children/:id/overview`。
- `/parent/**` 与 `/chat` 走 `React.lazy` 分包（孩子用不到的不下发）。
- 家长端列表游标分页，默认 20 条。
- `ErrorBoundary` 包在每个壳外层；孩子端兜底页用「页面走丢了」。
- 404 一律回 `/` 或静默 404（`/parent/**`）。
- 图片走平台 `<Image>`（`quality=80`），列表用 96px 容器。

## 十一、不做（避免结构膨胀）

- 不做侧边抽屉（孩子端）
- 孩子端页面深度 >1（详情一律用弹层或带返回的单页）
- Tab 嵌套 Tab
- 家长端移动/桌面两套布局（一套 + 断点加宽）
- 独立的"设置中心"聚合页（设置只在家长端「我的」）
