# UI 细节规范 v1（可检查的清单）

> 不是审美意见，是**能被检查的规则**。每条都有 ID、我们自己的数值、反例和自检方法。
> 依据：`PRODUCT.md`（原则）+ `DESIGN.md`（令牌与组件）+ `ui-ux-pro-max` 的 99 条 UX 指南（按布布场景筛过）+ 本项目已踩过的坑。
> 执行方式：写代码前扫一遍本组；提交前跑 `node scripts/audit-ui.mjs`。

---

## A. 对齐与网格（Q1–Q8）

| ID | 规则 | 我们的值 | 反例 |
| --- | --- | --- | --- |
| Q1 | **表单标签等宽**，控件左边缘连成一条竖线 | 孩子 96 / 家长 104 / 长标签 128 | 标签宽度随文字变 |
| Q2 | 标签超宽**整列加宽**，绝不省略号截断 | `.frow--wide` | `有任务等我…` |
| Q3 | 所有卡片内 padding 同页统一 | 孩子 16 / 家长 14 | 一张 16 一张 20 |
| Q4 | 卡片左边框强调色只用于**一张**卡片 | `3px` + 语义色 | 每张都强调 |
| Q5 | 列表右侧数值右对齐，文本左对齐 | `.kv b` / `.prow` | 数值跟着文字跑 |
| Q6 | 分组标题与首行同左基线 | 容器 padding 一致 | 标题缩进 4px |
| Q7 | 图标与文字同行时垂直居中，不基线下沉 | `align-items:center` | `vertical-align:baseline` |
| Q8 | 同页不混用两种圆角（除胶囊按钮） | 卡片 20/14 | 16 与 20 混用 |

**自检**：整页截图缩到 30%，看左边缘是否成竖线、卡片间距是否等距。

## B. 间距与节奏（Q9–Q16）

| ID | 规则 | 我们的值 |
| --- | --- | --- |
| Q9 | 一切间距是 **4 的倍数** | 4/8/12/16/20/24/32 |
| Q10 | 卡片之间 12px（家长）· 12–16px（孩子） | `--sp-3` |
| Q11 | 分区之间 24px + 分区标题 | `.sec` |
| Q12 | 段落行高 1.6–1.75，标题 1.2–1.3 | 见 §3.2 |
| Q13 | 正文行长 ≤ 34 汉字（375 宽约 22 字/行） | 不写超长句 |
| Q14 | 相邻可点元素间距 ≥ 8px | 两个按钮之间 |
| Q15 | 底部内容给导航留白 ≥ 导航高 + 16 | `padding-bottom` |
| Q16 | 安全区：底部 `env(safe-area-inset-bottom)` | 导航/弹层 |

**反例**：按钮贴在一起（`gap:0`）、内容被导航压住、刘海屏下弹层按钮被遮。

## C. 字体与数字（Q17–Q24）

| ID | 规则 | 我们的值 |
| --- | --- | --- |
| Q17 | 中文一律系统栈，**不加载中文 webfont** | `--font-kids` |
| Q18 | 数字用 Baloo 2 + `tabular-nums`（变长不跳） | `--font-number` |
| Q19 | 孩子端正文 ≥16px、辅助 ≥14px、12px 仅导航标签 | §3.2 |
| Q20 | 同页字号层级 ≤4 级 | Display/H1/Body/Note |
| Q21 | 不为"好看"加负字距；中文不 letter-spacing | `0` |
| Q22 | 数字与单位之间不空格（100个），中文与数字之间空格（读了 20 分钟） | — |
| Q23 | 不用全角标点混排英文；不用「」以外的引号风格 | 统一「」 |
| Q24 | 最多两级加粗（700/800），不用 900 | — |

**反例**：`font-size:13px` 的正文、`letter-spacing:-.02em` 的中文、数字跳动导致布局抖。

## D. 颜色与对比（Q25–Q32）

| ID | 规则 | 我们的值 |
| --- | --- | --- |
| Q25 | 正文 ≥4.5:1；占位文字同样 ≥4.4:1 | `#7E7396` |
| Q26 | 白字只放 `--k-grad-cta` / `#7C3AED` / `#DB2777` 上 | §2.6 |
| Q27 | 金色只做图标/填充，金色数字用 `#A16207` | — |
| Q28 | 颜色不单独承载信息（达标 = 色 + 印章 + 文案） | — |
| Q29 | 孩子端**不出现红色警告**（家长端才用 `--k-danger`） | — |
| Q30 | 语义色不混用：成功绿只表示完成，不做装饰 | — |
| Q31 | 禁用态用 opacity .45 + `pointer-events:none`，不改色相 | — |
| Q32 | 不使用纯黑 `#000`、纯灰 `#999` | 用 `--k-text` / `#7E7396` |

**反例**：粉底白字（2.1:1）、浅灰占位（2.3:1）、只靠红绿区分成功失败。

| ID | 规则 | 我们的值 |

## F. 表单（Q39–Q48）

| ID | 规则 |
| --- | --- |
| Q39 | 每个输入都有可见 label，**placeholder 不能当 label** |
| Q40 | label 用 `for` 关联 input（或包裹） |
| Q41 | 错误显示在**对应字段下方**，不用顶部汇总唯一提示 |
| Q42 | 错误文案说"怎么改"，不说"格式错误" |
| Q43 | 提交时按钮进入 loading 且禁用（防重复提交） |
| Q44 | 键盘类型正确：手机号 `inputmode=numeric`、密码 `type=password` |
| Q45 | 密码可切换显示（眼睛按钮，有 aria-label） |
| Q46 | 必填用 `*`，不预先红框 |
| Q47 | `autocomplete` 正确（tel / current-password / new-password） |
| Q48 | 表单提交后必有结果：成功提示或错误说明，**不许静默** |

## G. 列表与卡片（Q49–Q56）

| ID | 规则 |

| Q49 | 一行只有**一个右侧值**；要两个值就拆两行 |
| Q50 | 行高 56（单行）/ 72（双行）；整行可点 ≥40 |
| Q51 | 卡片里不嵌套卡片 |
| Q52 | 空列表给"为什么空 + 一个能立刻做的动作" |
| Q53 | 列表项文案截断用两行 + 省略，不截一行 |
| Q54 | 分组标题可带计数（`2 / 6`），不写"共 2 条" |

## H. 状态（Q57–Q66）

| ID | 规则 |
| --- | --- |
| Q57 | 加载 >300ms 才出骨架；<300ms 不闪 |
| Q58 | 骨架屏形状必须贴近真实内容（不是灰条乱码） |
| Q59 | 空态：一句人话 + 一个动作；禁止「暂无数据」 |
| Q60 | 错误态：说明 + 重试 + 出口；禁止「系统错误 / 500」 |
| Q61 | 离线：顶部细条 + 已完成项标「待同步」，不清空用户操作 |
| Q62 | 成功：toast 或状态变化，2s 消失；不堆叠 |
| Q63 | 禁用：视觉可辨（opacity .45）+ 不可点 |
| Q64 | 额度/次数用完：说清"什么时候恢复"+ 出口 |
| Q65 | 危险操作（删除/注销）二次确认，措辞说清后果 |
| Q66 | 任何状态都保留"下一步能做什么" |

## M. 孩子端专项（Q93–Q100）

| ID | 规则 |
| --- | --- |
| Q93 | 一屏一个主动作，两个同权重按钮 = 错误 |
| Q94 | 不出现分数/百分比；进度用格子或点阵 |
| Q95 | 不出现排行榜、不出现别的孩子数据 |

| Q99 | 不能让孩子误入家长端：齿轮 56px 无文字 |
| Q100 | 错误/失败对孩子用「没关系，先…」，不用红色 |

## 自检脚本

```bash
node scripts/audit-ui.mjs            # 检查 prototype/hifi 与 client/src
node scripts/audit-ui.mjs --strict   # 有 High 项即退出码 1
```

检查项：硬编码颜色 · 非阶梯字号 · 100vh · 标签省略号 · 触控尺寸 · 无限动画 · emoji · 缺失 aria-label 的图标按钮。

---

## 用法

1. **写页面前**：只看对应组（表单页看 F、列表页看 G、状态看 H）。
2. **写完**：跑脚本，High 必须清零。
3. **提测前**：截图缩到 30% 看对齐；开 `prefers-reduced-motion` 看反馈是否还在。
