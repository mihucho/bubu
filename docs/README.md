## 四·五、根目录脚本

| 脚本 | 用法 |
| --- | --- |
| `./update.sh` | 拉取 GitHub main 并覆盖到当前目录（默认备份旧文件到 `.update-backup/`） |
| `./update.sh --dry-run` | 只看会变更哪些文件，不落盘 |
| `./update.sh --force` | 连 `.env` 一起覆盖（慎用） |
| `./update.sh --no-backup` | 不备份 |
| `./update.sh --help` | 帮助 |

默认保留：`.env*` · `node_modules/` · `dist/` · `.git/` · `.spark*`。
**注意**：本地有未推送的改动时，更新会用远端版本覆盖它们（先备份，可回滚）。
