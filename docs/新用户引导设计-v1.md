# 新用户引导设计 v1（Onboarding）

> 专家路由：`/expert-design --onboarding` + `/expert-product --funnel`（设计 × 产品）
> 目标：**家长 3 分钟内完成必要配置，孩子 1 分钟内获得第一次惊喜。**

---

## 一、先定三条原则

**原则 1：引导分两段，不要合成一段。**
家长段 = 配置 + 合规（必须，可跳过的尽量可跳）；孩子段 = 第一次体验（不能有表单）。
把"设任务"塞进注册流程，是家长流失的第一原因。

**原则 2：默认值优先，选择多于输入。**
孩子姓名可输入，但头像选预设、任务选模板、时长用推荐值。**打字次数上限：1 次（孩子昵称）。**

**原则 3：每屏只问一个决定，且中途可退出可续上。**
进度落库（`setup_step`），杀进程回来接着走，不从第 1 步重来。

---

## 二、当前实现的问题（作为设计起点）

现状：`ProfileGate` 判定无档案 → 跳 `/setup`；`SetupPage` 只有「孩子昵称 + 我是谁 + 开始使用」两个字段，提交后直接 `navigate('/')` 进孩子端。

| 问题 | 后果 |
| --- | --- |
| 没有出生年 | 无法选 6–8 / 9–12 分龄模板（v3.1 决策依赖它） |
| 没有家长身份确认与隐私同意 | 不满足 PIPL「14 岁以下需监护人同意」与未成年人网络保护条例 |
| 没有家长门 | 引导完直接进孩子端，`/parent` 裸奔 |
| 没有模板确认 | 后端自动塞 6 个任务 / 6 个商店，家长不知道它们在 |
| 完成后没有"首个惊喜" | 孩子第一次看到的是任务列表，不是成就 |
| 白字压 `#FF85C1` 渐变 | 2.24:1，全流程主标题不可读 |
| 按钮 48px（h-12） | 孩子端不足 72px |

## 三、流程全图

```
启动
 ├── 已登录 + 已引导 ────────────→ 孩子端首页（或选人页）
 ├── 已登录 + 未引导（中断续上）──→ 回到上次那一步
 └── 未登录
      ↓
 [0] 登录 / 注册                （已有账号体系，客户端需补齐页面）
      ↓
 [1] 隐私与监护人同意            （必填，唯一不可跳过）
      ↓
 [2] 欢迎 + 一句话价值            （可跳过：直接下一步）
      ↓
 [3] 添加第一个孩子              头像(预设) → 昵称 → 出生年 → 你被叫作
      ↓
 [4] 选模板                     学前 / 小学低年级 / 我自己来
      ↓
 [5] 看一眼将启用的任务与商店      「就这样开始」/「我去改」
      ↓
 [6] 设家长门                    认知题 + PIN（4–6 位）
      ↓
 [7] 使用管理（推荐值预填）       每日 40 分 / 休息 20 分 / 睡眠 21–07
      ↓
 [8] 完成 → 直接进孩子端 → 首次体验引导
```

**步数**：家长段 8 屏，其中真正需要决策的只有 4 屏（3/4/6/7），其余是确认。目标 **≤3 分钟 / ≤1 次打字 / 0 次上传人脸**。

## 三·五、两条入口链路：豆包内 / 不在豆包内

**只判断一件事：在不在豆包内。** 不做微信、浏览器、其它 WebView 的细分。

| 环节 | 在豆包内 | 不在豆包内（微信扫码 / 浏览器） |
| --- | --- | --- |
| 第 0 步 | **跳过登录页**：平台 SSO 自动注入 | 手机号登录页（无豆包按钮） |
| 首次进入 | 「进入 / 绑定账号」页（进入=新建家庭；绑定=并进原家庭） | 直接开始引导第 1 步 |
| 家长门 | 两者相同（6 位家长密码） | 同左 |
| 说说话 | 正常对话 | **只读**（见下） |
| 导出图片 | 正常保存 | 正常保存（微信内可长按保存） |

> 判定实现：`inDoubao = UA 含 Doubao 或平台注入标记`。除此之外全站不做环境分支。

### 微信（不在豆包内）用户的首次说说话

第 8 步完成后孩子会点进「说说话」，此时看到的是**只读态**。必须有一次性解释，否则孩子会以为坏了。

```
布布  小月亮的好朋友              [只读]
  今天你读了 20 分钟，还差 2 个任务就开宝箱啦      ← 历史/回顾仍可看

  布布只在豆包里陪你聊天
  ┌────────────────────────────┐
  │   让爸爸妈妈用豆包打开       │
  └────────────────────────────┘
```

**一次性气泡（首次进入该页时出现，点掉即消失）**

> 「布布要去豆包里才能陪你聊天，让爸爸妈妈用豆包打开就好啦。」

规则：
1. 只弹一次（按 child 记），不重复打扰
2. 文案里不出现"不支持""不可用"这类否定词
3. 家长端「我的」里能查到这个状态：「孩子当前在微信里打开，AI 对话不可用」，并附一句"用豆包打开即可"
4. **不影响其他功能**：任务、阅读、运动、商店、心愿、闯关、签到全部照常

### 首次体验 5 步在非豆包环境下的差异

| 步骤 | 在豆包内 | 不在豆包内 |
| --- | --- | --- |
| ① 点任务卡提示 | ✅ | ✅ 相同 |
| ② 盖章得星 | ✅ | ✅ 相同 |
| ③ 宝箱说明 | ✅ | ✅ 相同 |
| ④ 商店许愿 | ✅ | ✅ 相同 |
| ⑤ **布布先开口** | ✅ 布布主动说第一句 | ❌ 改为「去小信箱看看」+ 只读解释气泡 |

## 四、逐屏详细设计

### [0] 登录 / 注册

```
        ┌────────────────────────┐
        │        (应用 Logo)      │
        │   布布的学习小天地       │
        │  每天一点点，成长看得见    │
        │                        │
        │  ┌──────────────────┐  │
        │  │   手机号          │  │  44px
        │  └──────────────────┘  │
        │  ┌──────────────────┐  │
        │  │   密码            │  │
        │  └──────────────────┘  │
        │  ┌──────────────────┐  │
        │  │     登 录         │  │  52px 主按钮
        │  └──────────────────┘  │
        │      没有账号？注册 →    │
        └────────────────────────┘
```
- 家长端密度（40/44px），不用儿童尺寸——这一步是大人操作。
- 错误文案：「手机号或密码不对，再试一次」。连续 5 次失败隐藏登录按钮 60 秒（防撞库）。
- **不做第三方登录**（Kids 类合规麻烦、审核成本高）。
- 孩子端永远看不到这一步（登录态持久 + 设备记住）。

### [1] 隐私与监护人同意（唯一硬门槛）

```
┌──────────────────────────────┐
│ 在开始之前                      │
│                              │
│ 这款应用会记录孩子的学习、心情和    │
│ 聊天内容，因此需要家长确认：       │
│                              │
│ □ 我是孩子的监护人，已阅读并同意     │  ← 不预勾选
│   《隐私政策》《儿童个人信息保护规则》 │
│ □ 同意为孩子建立独立档案（昵称、头像） │
│                              │
│ 我们不会向第三方提供孩子的任何信息，  │
│ 也不会展示广告。                 │
│                              │
│   ┌────────────────────────┐  │
│   │      同意并继续          │  │  ← 两项未勾选时 disabled
│   └────────────────────────┘  │
│   不同意，退出                  │
└──────────────────────────────┘
```
- **勾选框默认不勾**（预勾选属违规设计）。
- 不同意 → 退出应用（不给"随便看看"的旁路）。
- 记录 `consent_at`、`consent_version`、IP/设备指纹（合规留证）。
- 政策变更时二次弹窗（`consent_version` 不匹配）。

### [2] 欢迎

```
        (布布挥手的插图)
     这是你家孩子的小天地
  做完一件事、读到一本书，都会变成星星
        ┌────────────────┐
        │   开始设置       │
        └────────────────┘
            跳过 →
```
- 可跳过（跳过 = 直接到 [3]，不省 [1]）。
- 插图不写功能列表，只给情绪。

### [3] 添加第一个孩子

```
    给孩子建一个小天地           1/3
   ┌────────────────────────┐
   │        (大头像)          │  ← 点一下换头像
   │                         │
   └────────────────────────┘
   头像： [🐰][🐻][🦊][🐱][🐶][🦄][📷 相册]
   昵称： ┌──────────────┐
          │  小月亮        │  44px，maxLength 10
          └──────────────┘
   出生年： [6岁][7岁][8岁][9岁][10岁]   ← 决定分龄模板
   你被叫作： [妈妈][爸爸][奶奶][爷爷][其他]
        ┌────────────────┐
        │     下一步       │
        └────────────────┘
```
- **头像用预设卡通**，相册可选；**不做人脸识别、不强制上传**（PIPL 最小化）。
- 出生年用"岁数"不用"年份"（家长更快，孩子 6–10 岁区间用 5 个按钮替代年份滚动）。
- 昵称实时出现在预览："这就是 小月亮 的小天地"。
- 校验：昵称非空、≤10 字；不合法时**行内红字**，不弹 toast。

### [4] 选模板

```
   选一套现成的，随时能改          2/3
 ┌──────────────────────────┐
 │ ◉ 小学低年级（推荐）        │  ← 按出生年自动预选
 │   4 个任务 · 6 个奖励 · 每周达标 8 项
 ├──────────────────────────┤
 │ ○ 学前                      │
 │   3 个任务 · 奖励更简单
 ├──────────────────────────┤
 │ ○ 我自己来                  │
 │   从空白开始，稍后在家长端添加
 └──────────────────────────┘
        ┌────────────────┐
        │   下一步        │
        └────────────────┘
```
- 默认选中推荐项（依据出生年）。
- 卡片上**直接列出会预置的条目数**，避免"我不知道它给我塞了什么"。

### [5] 看一眼将启用的内容

```
   这就是小月亮要做的事            3/3
 ┌ 本周任务 ─────────────────┐
 │ 🌍 大果外教作业  2 次  ⭐3  │
 │ 🧹 小帮手做家务  3 次  ⭐2  │
 │ 🐣 叫叫阅读     5 次  ⭐1  │
 │ 🎒 学校作业     7 次  ⭐2  │
 ├ 星星商店 ─────────────────┤
 │ 📚 选一本新绘本  5⭐  🚲 骑车 10⭐│
 │ … 共 6 项                  │
 └──────────────────────────┘
   [ 就这样开始 ]   [ 我去改一改 ]
```
- 这一屏是**信任建立点**，先给看再给用。
- 「我去改一改」→ 直接进家长端任务页（不打断引导，保存后可"继续设置"）。

### [6] 家长门（认知题 + PIN）

```
   给大人设一道门                  
   孩子点到这里会看到一道题，答对才能进

   点一下「七」
   ┌──────┐┌──────┐
   │  七  ││  二  │     96px 大按钮
   └──────┘└──────┘
   ┌──────┐┌──────┐
   │  九  ││  五  │
   └──────┘└──────┘

   再设 4 位数字密码
   ┌──┐┌──┐┌──┐┌──┐   （可改 6 位）
   └──┘└──┘└──┘└──┘
        ┌────────────────┐
        │     完成        │
        └────────────────┘
```
- 认知题随机从 20+ 题库取，**每次进入都换**；PIN 只在连续错题后出现（降低家长负担）。
- 忘记 PIN：走"手机号验证码"重置（不做密保问题）。

### [7] 使用管理（推荐值预填）

```
   给孩子的使用时间                  
   每天能玩      40 分钟    [－][＋]
   每玩        20 分钟休息 5 分钟
   睡觉时间      21:00 – 07:00
   
   ☑ 先用推荐设置（3–10 岁建议值）
        ┌────────────────┐
        │   开始使用      │
        └────────────────┘
     稍后可在「家长 → 使用管理」调整
```
- 一键用推荐值；改动只影响未来，不追溯。
- 这是**合规要求**（未成年人模式建设指南），不能跳过，但可一键。

### [8] 完成 → 孩子端首次体验

**关键决定：完成后落地的是孩子端首页，不是家长端。**
理由：这一秒的情绪决定产品是否被继续使用——先给孩子一次成功。

```
[完成] → 切到孩子端 shell → 首页 + 首次引导气泡
```

**首次体验引导（孩子端，一次性）**

| 顺序 | 触发 | 呈现 | 消失条件 |
| --- | --- | --- | --- |
| 1 | 首页加载 | 任务卡上浮出气泡「点这里，就能得星星」+ 手指动画 | 点任意任务卡 |
| 2 | 第一次打卡 | 盖章 + 星星飞入 + 语音"哇，小月亮好棒！" | 自动 |
| 3 | 打卡后 | 宝箱区闪烁一次 + 「集满 8 个能开宝箱」 | 3 秒或点击 |
| 4 | 首次进商店 | 「想要的可以先许个愿，爸爸妈妈帮你定价」 | 关闭 |
| 5 | 首次进说说话 | **布布先开口**："小月亮你好呀，今天想聊什么？" | 发第一条消息 |

规则：**同时只允许一个引导气泡**；任何引导都可点掉；不重复出现（`first_run_done` 按 child 记）。

## 五、另外三个入口场景

### 5.1 添加第二个孩子

```
家长端 → 孩子管理 → + 添加孩子
  [3] 添加孩子（同上）
  [4'] 用老大的任务和商店？  ○ 复制   ○ 从模板重选   ○ 空白
  → 完成（不再走 PIN/使用管理，继承家庭设置）
```
- **继承家庭级设置**（PIN、使用管理、边界），不重复问。
- 复制只复制**定义**，不复制进度（星星从 0 开始）。
- 新孩子落地：选人页 → 进入新孩子首页 + 首次体验引导（每个孩子独立一次）。

### 5.2 孩子切换

选人页仅在 ≥2 个孩子时出现；设备记住上次选择；「我的」页长按 1 秒"换一个人"防误触。

### 5.3 回访（第 2 天 / 第 7 天未回）

| 场景 | 孩子端 | 家长端 |
| --- | --- | --- |
| 次日未打卡 | 首页布布气泡"昨天你差一点就开宝箱啦" | 无推送 |
| 3 天未打开 | — | 概览页一条"小月亮已经 3 天没来了"（不推送） |
| 7 天未打开 | — | 周报里空态 + 一条建议 |
| 首次全达标 | 庆典 | 概览页「待你处理：可以兑现心愿」 |

> 儿童产品**不做召回推送轰炸**；不做"你失去了 X 天连续"的损失厌恶文案。

## 六、边界与异常

| 情况 | 处理 |
| --- | --- |
| 引导中途杀进程 | `setup_step` 落库，回来续上原步骤 |
| 昵称重复/超长 | 行内红字（不弹窗），输入框抖动 200ms |
| 昵称含敏感词 | 提示"换一个试试"，给 3 个候选名 |
| 网络失败 | 保留已填内容，重试按钮；不清空表单 |
| 家长不填出生年 | 默认 7 岁 + 推荐模板，并在 [4] 标注"可稍后修改" |
| 只填了卡片就退出 | 数据不落库（除 [1] 的同意记录），避免脏档案 |
| 家长门忘记 PIN | 验证码重置 |
| 添加第 6 个孩子 | 上限 4 个（超出提示"建议分账号"） |
| 不同意隐私条款 | 退出，不提供旁路 |

## 七、验收标准

| 项 | 标准 |
| --- | --- |
| 首次完成率 | ≥85%（从 [1] 到 [8]） |
| 耗时 | P50 ≤3 分钟，P90 ≤6 分钟 |
| 打字次数 | ≤1 次（孩子昵称） |
| 跳过率 | [2] 跳过率不限，[1]/[6]/[7] 不可跳过 |
| 到首个打卡 | 从 [8] 落地到首次打卡 ≤60 秒 |
| 可读性 | 全流程无 <4.5:1 的文字对比度 |
| 触控 | 家长段 ≥44px，孩子段 ≥72px |
| 合规 | 同意记录可审计；不同意无法进入 |
| 二孩 | 第二个孩子完成时间 ≤60 秒（复制配置） |

## 八、埋点漏斗

```
app_open → login_success → consent_granted → child_created
 → template_selected → template_previewed → gate_set → limits_set
 → first_home_view → first_task_tap → first_star_earned
```

关键诊断点：
- `child_created → template_selected` 流失高 → 模板文案没说服力
- `limits_set → first_home_view` 流失高 → [7] 太长（改为一键推荐）
- `first_home_view → first_task_tap` 超过 60 秒 → 引导气泡不够明显
