# 页面清单与链路 v1（96 屏 · 实现清单）

> **用途**：这份是转 React 前的交付清单。每一屏都有：路由、入口、出口、优先级。
> 原型基准：`prototype/redesign.html`（96 屏 · 零 emoji · 可点击）。
> 判据：**任何一个列表都要有详情页；任何一个实体都要有编辑页；任何一个流程都要有退出路径。**

---

## 一、全局结构

```
GateShell   登录 / 注册 / 忘记密码           375 · 家长密度 44px
SetupShell  引导 8 步                        375 · 顶部进度 + 底部单按钮
KidShell    孩子端 5 tab                     430 · 儿童密度 72px
ParentShell 家长端 5 tab                     720 · 家长密度 40px（平板可两栏 760+）
```

| 端 | 强制路径 | 说明 |
| --- | --- | --- |
| 家长 | 登录 → 同意 → 加孩子 → 模板 → 预览 → 家长密码 → 使用时间 → 完成 | 完成后**落地孩子端首页** |
| 孩子 | 选人 → 账号密码 → 首页 | 首次登录提示改密码（可跳过） |
| 家长端 | 孩子端齿轮 → 家长密码 → 概览 | 20 分钟免重复；密码 6 位、5 次错误静默退回 |

## 三、五条关键链路（照着点一遍就能验收）

### 1. 家长开箱（0 → 可用）

```
登录 → 同意 → 加孩子 → 选模板 → 预览 → 设家长密码 → 使用时间
     → 落地孩子端首页（首次引导气泡）
```

### 2. 家长给孩子开通账号

```
孩子 tab → 孩子详情 → 账号与登录（弹层）
   → 复制账号 BUBU7K2M9X / 初始密码 482913 / 二维码
   → 孩子在他设备上扫码 → 首次登录 → 提示改成自己的密码
```

### 3. 孩子完成一次打卡（两条分支）

```
必需拍照：首页任务行 → 拍照 → 确认 → 星星入账
需要确认：首页任务行 → 提交 → 「等爸爸妈妈确认」
        → 家长通知中心 → 待确认详情 → 确认 → 星星入账（24h 未确认自动通过）
```

### 4. 家长看变化

```
概览（今日卡）→ 周期报告（按任务周期分组 + 区间统计）→ 导出预览 → 保存图片
记录 → 日记详情 / 对话详情（含布布查了什么）
```

### 5. 二孩隔离

```
选人页（各自主色）→ 各自孩子密码 → 各自任务/星星/商店/心愿/宠物/闯关/日记/AI 记忆
家长端：孩子列表 → 详情 → 复制配置（只复制定义，不复制进度）
```
