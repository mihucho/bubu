# 页面结构设计 v1

> 前置：`docs/整体设计优化-v1.md`（双壳、5 tab、react-query）· `docs/数据模型设计-v1.md`
> 定稿结论：**4 个壳 + 3 组路由 + 一套共享 API**；孩子端 5 tab + 3 张首页卡片；家长端 7 个二级页。

---

## 一、壳（Shell）

| 壳 | 用途 | 宽度 | 导航 | 视觉密度 |
| --- | --- | --- | --- | --- |
| `GateShell` | 登录 / 注册 / 隐私同意 | 375 | 无 | 家长密度（44px） |
| `SetupShell` | 引导流程（步进） | 375 | 顶部进度点（1/3 · 2/3 · 3/3），无底部导航 | 家长密度 |
| `KidShell` | 孩子端 | 430 居中 | 底部 5 tab，72px + 安全区 | 儿童密度（72px） |
| `ParentShell` | 家长端（家长门后） | 720 居中 | 顶部标题 + 横向二级 tab，无底部导航 | 家长密度（40px） |

```
GateShell ──登录成功──> SetupShell（未完成引导）
                         └──完成──> KidShell（落地孩子端首页）
KidShell ──齿轮 + 家长门──> ParentShell
ParentShell ──"回到孩子端"──> KidShell（重定向到当前孩子首页）
```

## 三、路由守卫逻辑

```ts
// router guard 顺序
1. 未登录                     → /auth/login
2. 已登录 & !consent_at       → /setup/consent（且其它 /setup/* 全部重定向到此）
3. 已登录 & !setup_completed   → /setup/{setup_step}（断点续上）
4. 访问 /                              & children.length > 1 & !currentChildId → /choose
5. 访问 /parent/**            & !parentMode.unlocked → 404（静默）
6. 20 分钟无操作               & 在 /parent/** → 自动上锁并回 /me
```

`parentMode` 状态存内存（不落 localStorage），刷新即失效。

## 八、状态管理约定

| 状态 | 归属 | 说明 |
| --- | --- | --- |
| 登录态 / family | `SessionContext` + `GET /api/auth/me` | 只在启动与登录后拉一次 |
| children[] / currentChildId | `FamilyContext` | currentChildId 存 localStorage（设备记忆） |
| 家长门解锁 | `ParentModeContext`（内存） | 刷新失效；20 分钟无操作自动锁 |
| 服务端数据 | react-query | key 约定见下 |
| 打卡乐观更新 | `useTaskCheckin` mutation | `onMutate` 预加，`onSettled` 服务端为准 |
| 本地离线队列 | `useOfflineQueue`（localStorage） | 打卡/心情；带幂等键补交 |

**queryKey 约定**

```
['overview', childId]                首页一次拿全
['tasks', childId, weekStart]
['ledger', childId, {cursor}]
['shop', childId]
['wishes', childId]
['quests', childId, status]
['chat', childId, sessionId]
['reports', childId, weekStart]
['parent','children', familyId]
```

失效规则：任何加/减星 mutation → invalidate `['overview', childId]` + `['ledger', childId]`；打卡成功 → invalidate `['tasks', childId]`。

## 九、API 契约（统一前缀 `/api`）

| 方法 | 路径 | 端 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/register` | Gate | 注册家庭账号 |

| POST | `/reading` / `/exercise` / `/mood` | Kid | 记录（幂等） |

| GET/POST/PATCH | `/quests` | Kid/Parent | 闯关 |
| POST | `/chat/stream` | Kid/Parent | SSE 流式对话（含工具循环） |
| GET | `/chat/sessions` · `/chat/messages` | Kid/Parent | 历史 |
| GET | `/reports/weekly/:weekStart` | Parent | 周报（无则生成） |
| GET | `/reports/daily/:date` | Kid/Parent | AI 日报 |
| POST | `/usage/session/start` · `/end` | Kid | 使用时长 |
| GET | `/usage/state` | Kid | 是否被拦截（休息/超时/睡眠） |
| POST | `/parent/unlock` | Gate | 家长门验证 |
| PATCH | `/family/limits` · `/family/boundary` | Parent | 使用管理与边界 |
| DELETE | `/children/:id/data` | Parent | 删除孩子数据（软删） |

**统一响应**

```json
{ "ok": true, "data": {}, "error": null }
{ "ok": false, "data": null, "error": { "code": "INSUFFICIENT_STARS", "message": "再攒 12 颗就能换啦", "retryable": false } }
```

## 十、加载 / 错误 / 空态策略

| 场景 | 孩子端 | 家长端 |
| --- | --- | --- |
| 首屏加载 | 骨架（宝箱 + 3 行任务），**不用 spinner** | 骨架 3 行 |
| 局部刷新 | 静默（react-query `isFetching` 不显示） | 顶部细进度条 |
| 可重试错误 | 顶部细条「没接上，正在重试」+ 自动重试 2 次 | 行内红字 + 重试按钮 |
| 不可重试错误 | 儿童化兜底页 + 回首页按钮 | 明确说明 + 联系支持 |
| 空态（无记录） | 插图 + "今天还没有故事，先闯一关吧" + 主按钮 | 说明 + "用模板开始" |
| 使用被拦截 | `UsageWall` 全屏（无内容） | — |
| 离线 | 队列模式 + 顶部细条 | 只读 + 提示 |

## 十三、路由级性能与边界

- 孩子端首屏只请求 **1 个聚合接口**（`/children/:id/overview`），避免 5 个请求瀑布。
- 家长端列表页分页（游标），默认 20 条。
- `/chat` 懒加载（体积最大）。
- 所有 `/parent/**` 用 `React.lazy` 分包（孩子用不到，不下发）。
- 404 一律重定向 `/`，不显示技术错误页。
- `ErrorBoundary` 包在每个壳外层；孩子端兜底页文案：「咦，页面走丢了，回首页吧」。

## 十四、不做（避免结构膨胀）

- 不做侧边抽屉导航（孩子端）
- 不做多级嵌套（孩子端深度 ≤1）
- 不做 Tab 嵌套 Tab
- 不为家长端做移动/桌面两套布局（720 单列 + 断点加宽）
- 不做空壳"设置中心"聚合页（设置只在家长端）
